Installing (first time)

  1. Tap Download Joggin above.
  2. Open the downloaded file (check your notifications or Downloads).
  3. If Android warns about "unknown sources", tap Settings and allow this browser/Files app to install apps, then go back.
  4. Tap Install. If Play Protect asks, choose Install anyway.

Joggin isn't on the Play Store, so Android shows the standard warnings for apps installed outside the store. That's expected.
